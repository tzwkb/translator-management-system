# 译员管理系统待完善清单

> 文档状态：未来计划｜日期：2026-07-16｜说明：本文各项均为尚待完善或确认的工作。

当前版本是可演示、可继续迭代的审批版。语言对费率、字段格式校验、详情页分组、子记录删除、客诉/质量/谈判联动、PO Excel 导入、agent dry-run / 幂等 / 防重已经接入；后端验收基线为 `71/71`。

## 一、上线必需

- 部署：改成 systemd 或 Docker 常驻运行，配置 HTTPS，不依赖终端临时启动。
- 密钥：生产环境固定设置 `JWT_SECRET`、`AES_KEY`，避免重启后 token 或加密能力变化。
- 数据库迁移：引入 Alembic，替代启动时的结构补丁，后续改表可升级/回退。
- 备份：数据库定时备份，并保留恢复流程。

## 二、业务功能待补

- 真登录：替换 demo 角色切换；agent 使用独立服务账号和受限权限。
- 财务权限细分：资源端、财务、boss、agent 的权限边界需要按实际上线角色拆清。
- 到期提醒：合同、NDA、最近联系、档期等提醒可以用 APScheduler 或外部定时任务。
- 发票回收流程：明确邮件回收、账单发送、支付状态回写是否纳入系统自动化。

## 三、自动化与体验

- 移动端适配：当前以桌面操作为主，移动端作为 V2。
- 文档/模板自动生成：从 schema 生成字段字典、导入模板和接口说明，减少人工同步成本。

## 四、仍需业务确认

- 系统角色范围是否扩到项目/前端等更多角色。
- 小明哥会议最后两项的具体含义，尤其“建模”相关表述。
