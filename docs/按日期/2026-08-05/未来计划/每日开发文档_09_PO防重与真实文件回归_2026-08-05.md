## 一、当日目标

- 防止同一原始文件被重复导入。
- 支持下载或复制异常行清单。
- 使用真实 Projectlist 样本完成回归。

## 三、计划数据结构

新增 `po_import_batches`：

| 字段 | 说明 |
|---|---|
| `id` | 导入批次 ID |
| `file_name` | 原文件名 |
| `file_sha256` | 文件内容哈希，唯一 |
| `sheet_name/header_row` | 识别结果 |
| `imported_rows/invalid_rows` | 批次数量 |
| `imported_by/imported_at` | 操作人和时间 |

PO 增加可空 `import_batch_id`。旧 PO 保持为空。

## 四、防重边界

- 完全相同文件再次确认导入时拒绝，并返回原批次时间和数量。
- 预览不占用哈希，不影响后续正式导入。
- 文件内容发生变化会产生新哈希；首版不承诺自动识别修改文件中的重复行。
- PO 号存在时继续沿用现有唯一性检查。
- 若业务要求反复修订同一日报，后续再增加稳定源记录 ID 或行级指纹。

## 五、真实文件回归

必须核对：

- 工作表和表头识别；
- 译员匹配结果；
- 翻译、LQA、小时类任务的数量来源；
- REP/WWC 折算；
- 币种、费率和金额；
- 结算月份及结算状态；
- 空行、合计行、跨行公式和日期单元格。

真实文件仅作为本地受控测试输入，不复制个人信息到公开测试夹具或日志。

## 七、验收标准

- 同一文件第一次导入成功，第二次导入返回明确的重复批次信息。
- 重复尝试不会新增任何 PO。
- 异常行清单可供资源端定位原 Excel 行。
- 对真实样本抽查的数量、费率、金额、月份和币种一致。
- 导入失败不留下半成品批次记录。
