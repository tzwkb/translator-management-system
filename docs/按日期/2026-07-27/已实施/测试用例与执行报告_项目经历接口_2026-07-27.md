# 项目经历接口测试用例与执行报告

> 文档状态：已执行 / 已验收｜日期：2026-07-27｜对应迁移：`20260724_0002`

测试对象：项目经历查询与新增接口、性别与主体类型读写、输入校验、权限、审计、旧字段兼容及现有业务回归

隔离策略：HTTP 验收自动启动临时服务并使用临时 SQLite；迁移专项使用临时数据库，不改动 `backend/app.db` 或 `data/app.db`。

## 一、验收

- 新增 `GET /api/translators/{tid}/project-experiences` 和 `POST /api/translators/{tid}/project-experiences`。
- 一个译员可保存多个当前及过往项目，每条记录具有稳定 ID 和独立角色。
- 列表按“当前项目优先、`start_date` 倒序、ID 倒序”返回。
- 项目名、合作来源、项目状态、日期、剩余量和语言对校验符合首版口径。
- 不存在的译员返回 404；viewer 和 agent 均不能新增项目经历。
- 新增项目经历会记录审计日志，读取和新增均不改写旧 `current_project/role`。
- `gender/entity_type` 可通过译员接口新增、编辑和读取，旧数据空值保持兼容。
- 核心 HTTP 验收由 `71/71` 增至 `88/88`，新增 17 项全部通过，原有 71 项持续通过。
- 迁移、Schema、待审幂等、数据质量、Docker、前端、Agent 和静态检查全部通过。
