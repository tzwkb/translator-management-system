# 译员导入模板交付记录

日期：2026-09-07。状态：本地代码及模板已完成，未部署公网。

## 变化

旧模板仅保存在历史文档目录，首页无下载入口；旧文件缺少当前必填的性别，还保留已停用的默认费率、是否双休、档期及自动评级输入。

首页新增“下载导入模板”，通过 `GET /api/export/translator-template` 返回固定版本的空白文件。资源位于 `backend/app/templates/translator_import_template.xlsx`，随现有 Docker 的 `COPY backend/app/` 打包，不需要数据库迁移。字段变化时须同步更新模板，并运行模板专项检查，防止文件和解析器不一致。

模板包含 35 列主表（含译员ID）、项目经历、名称映射、填写说明。数据页无示例记录。主表必填姓名、母语、入库日期、性别，配有下拉项和日期格式，冻结表头及前两列。项目经历的条件必填项及附表关联规则写在说明页。

导入接口优先按“译员导入”或“译员”名称选择主表，再回退到活动工作表。新增人工评级/原因的中文表头、`CAT 工具` 别名，以及“月结/累计结”输入兼容。保留现有新增、同ID覆盖、邮箱去重与部分行成功机制。默认费率仍按既有设计移出模板，未修改费率业务模型或原测试预期。
