# 译员自填链接使用说明

2026-09-07 · 本地版本

推荐两种方式并用：已有资料使用 [标准导入模板](../../../../backend/app/templates/translator_import_template.xlsx) 批量导入；新译员和资料补充使用自填链接。

## 资源负责人

1. 打开本地管理系统的“资料收集”，填写邀请邮箱。更新已有档案时同时填写译员ID；新译员留空。
2. 点击“生成链接”，复制并保存。默认有效期14天，可选7天或30天；链接只显示一次。
3. 将链接发给对应译员。译员无需后台账号。邮箱与邀请绑定，更换邮箱需重新邀请。
4. 在“提交资料 → 待审核”查看新旧值、语言对、报价和项目经历。资料不齐时填写处理意见，再点“退回补充”。译员可用原链接修改并重新提交。
5. 确认后点“审核通过并入库”。新译员的入库日期、初始状态及结算方式由你确认；默认初始状态为 Probation，结算方式为月结。

报价必须单独勾选“已核对报价和单位”。不勾选时仍会登记语言对，但不会修改费率。翻译、审校、MTPE 按千字或词；LQA、LQE 按小时。修改币种时必须补齐该语言对已有的费率，避免旧价格被当成另一币种。

同名或同邮箱申请会提示候选档案，需人工选择合并。若多个档案存在冲突，先在管理端处理重复档案，再审核。

“邀请记录”可以撤销链接。撤销后无法继续填写，该邀请的待审资料也不能入库。“重新邀请”会填回邮箱和译员ID，供你生成新链接；它不会自动撤销旧链接。

## 译员

打开完整邀请链接，填写基础资料、至少一组语言对，以及可选报价、专业能力和项目经历。表单有中英文标签，可在手机上使用。

标 * 的项目必填。当前项目还需开始日期、剩余字数及截止或结束日期；涉密项目可用代称。填写完成后勾选资料使用同意项，点击“提交资料”，看到回执即提交成功。

首次提交前不保存云端草稿，刷新或关闭页面可能丢失未提交内容。提交后如需修改，请联系资源负责人退回补充；退回后打开原链接，会恢复已提交的资料及处理意见。处理意见在链接页面显示，系统不会自动发邮件。

## 入库规则

- 审核前、拒绝后，正式档案保持原值；重复提交和重复审核不重复建档。
- 更新时，空白选填项保留原值；清空旧字段需在管理端操作。
- 未提交的语言对和费率保留。项目经历仅新增，完全相同的记录会跳过；旧经历的修订或删除在管理端完成。
- 译员补充说明保存在申请中，不覆盖后台内部备注；评级、合同、收款账户等内部字段不开放给译员填写。
- 链接到期后不能读取或提交，但到期前已提交的资料仍可人工审核。撤销链接则阻止待审入库。
- 审核期间若正式档案已被其他人修改，系统会要求刷新差异后重新审核。

## 本地使用与对外开放

本地管理入口：[http://127.0.0.1:9020/](http://127.0.0.1:9020/)。选择“资料收集”生成邀请。独立填写服务在端口9021运行。

以 `127.0.0.1` 开头的链接只能在这台电脑使用，不能直接发给外部译员。

对外使用时，应通过 HTTPS 发布独立入口 `app.intake_public:app`，并在管理服务中设置 `INTAKE_PUBLIC_BASE_URL` 为该站点地址，例如 `https://intake.example.com`。这是格式示例，不是已部署地址。管理服务 `app.main:app` 保持内网访问，不能把它整体转发到公网。

独立入口只提供填写页面和申请接口，不提供后台登录、译员列表、导出或内部管理接口。当前两个进程共享 SQLite 文件，这属于接口隔离，并非数据库权限的物理隔离。两侧必须使用相同数据库配置；先迁移，再启动服务。公开接口有请求体大小限制、输入校验、每进程每IP每分钟120次限流，且不会记录明文邀请令牌到数据库。

开发启动示例，在 `backend/` 目录下分别开两个终端运行：

```bash
# 先备份数据库并执行迁移
.venv/bin/python -m alembic upgrade head

# 终端一：内部管理服务
INTAKE_PUBLIC_BASE_URL=http://127.0.0.1:9021 .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 9020

# 终端二：独立填写服务
.venv/bin/python -m uvicorn app.intake_public:app --host 127.0.0.1 --port 9021
```

首次开放公网还需确定域名、HTTPS入口、固定配置及进程托管。当前版本没有发送邀请或发布公网地址。
