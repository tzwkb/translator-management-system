# 每日开发文档 11：多支付方式接口

> 文档状态：未来计划（未实施）

## 一、当日目标

- 支持一个译员维护多个支付账户。
- 支持微信、支付宝、个人银行卡、对公人民币、对公美金。
- 复用现有 AES-256-GCM 加密、默认脱敏和明文查看审计。

## 三、支付方式与首版字段

| 方式 | 必填字段 | 可选字段 |
|---|---|---|
| 微信 | 实名、微信号或手机号 | 收款码文件后续关联 |
| 支付宝 | 实名、支付宝账号或手机号 | 备注 |
| 个人银行卡 | 收款人、银行、银行卡号 | 支行、证件号 |
| 对公人民币 | 公司/账户名、开户行、账号 | 税号、支行 |
| 对公美金 | Beneficiary、账号或 IBAN、银行名、SWIFT/BIC | 银行地址、Routing/ABA、中转行 |

敏感字段统一放入加密 JSON，不在审计日志、错误信息或默认响应中输出明文。

## 四、接口计划

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/translators/{tid}/payment-accounts` | 返回账户列表和脱敏字段 |
| POST | `/api/translators/{tid}/payment-accounts` | 新增账户 |
| PUT | `/api/translators/{tid}/payment-accounts/{aid}` | 编辑账户 |
| DELETE | `/api/translators/{tid}/payment-accounts/{aid}` | 删除账户 |
| GET | `/api/translators/{tid}/payment-accounts/{aid}/reveal` | 查看明文并记审计 |

## 五、业务规则

- 每个译员、每种币种最多一个默认账户；设为默认时取消同币种其他默认项。
- 对公人民币默认币种为 CNY，对公美金默认币种为 USD。
- 删除默认账户允许执行，但必须提醒用户重新指定默认账户。
- 更新请求中未提供的敏感字段保持原值，不得被空字符串覆盖。
- 路径中的账户必须属于该译员，禁止跨译员访问。

## 七、验收标准

- 同一译员可保存五类账户和多个币种账户。
- 列表默认只返回后四位等脱敏内容。
- 明文接口仅编辑角色可用，并写入审计日志。
- 数据库和普通日志中搜索不到测试账号明文。
- 各支付方式缺必填字段时返回明确的字段错误。
- 跨译员查看、修改或删除返回 404。
